# Security policy

## Reporting

Please report suspected vulnerabilities privately through GitHub's
**Security → Report a vulnerability** flow. Do not open a public issue for
credential leaks, save corruption or data-loss bugs before a fix is available.

## Secret handling

This repository intentionally ships **without** signing credentials.

- `keystore.properties` and all `*.jks`, `*.keystore`, `*.p12`, `*.p8` and
  `*.key` files are gitignored.
- `android/` and `ios/` are generated by Expo prebuild and are not committed.
- CI fails if signing material is tracked.
- Release builds read the keystore from the developer machine at Gradle time;
  the password is never written into the generated project.

If you believe a credential was committed, treat it as compromised, rotate the
upload key in Play Console, and open a private report.
